# 장면갈피

대화를 이미지 카드로 저장하는 정적 웹 앱. 별도 설치나 빌드가 필요 없습니다.

## GitHub Pages

1. ZIP을 풀고 index.html이 저장소 최상위에 오도록 파일과 fonts 폴더를 전부 업로드합니다.
2. Settings → Pages → Deploy from a branch를 선택합니다.
3. main 브랜치, / (root)를 선택하고 Save를 누릅니다.
4. 배포 완료 후 Pages에 표시되는 주소로 접속합니다.

## 파일

- index.html: 편집 화면
- style.css: 화면 스타일과 모바일 대응
- app.js: 대화 분석, 설정, 카드 렌더링, 이미지 저장
- editor-session.js: 원문·커서·스크롤 위치 보관과 복원
- gulim.js: Microsoft 굴림 읽기와 기기 내 캐시
- zip.js: 여러 장을 ZIP으로 저장
- fonts/: 내장 글꼴 및 라이선스

## 사용

`이름: 대사`로 발화자를 구분합니다. `---`를 한 줄에 단독으로 입력하면 장이 나뉩니다. 지문은 일반 문장이나 `*지문*`으로 적습니다.

원문과 편집 위치는 같은 탭의 sessionStorage에 임시 보관됩니다. 탭을 닫거나 브라우저 데이터를 지우면 사라질 수 있으니 중요한 원문은 별도로 보관하세요. 꾸미기 설정과 사진 배경은 새로고침 시 초기화됩니다. 기존 사이트의 데이터는 새 GitHub 주소로 옮겨지지 않습니다.

모바일 사진 저장 버튼은 공유 메뉴를 엽니다. 여기서 이미지 저장을 선택하세요. 지원되지 않는 브라우저에서는 이미지를 길게 눌러 저장합니다. 웹사이트에서 사진 앱에 자동 저장하지는 못합니다.

## 글꼴

프리텐다드·본고딕·본명조·백묵 굴림은 포함되어 있습니다. Microsoft 굴림 파일은 포함되지 않았습니다. 해당 옵션은 기기에 설치된 글꼴이나 직접 선택한 gulim.ttc를 사용합니다. 선택한 파일은 브라우저에 보관되고 서버로 전송되지 않습니다. 백묵 굴림과 Microsoft 굴림은 서로 다른 글꼴입니다.

## 로컬 실행

Python이 있으면 이 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 으로 접속합니다. 모바일 공유 기능은 HTTPS로 배포한 주소에서 사용하세요.

## 확인 범위

JavaScript 구문, 파일 참조, ZIP 무결성과 스크롤 복원 로직을 확인했습니다. 실제 iPhone Safari의 키보드 및 앱 전환 동작은 기기에서 추가 확인이 필요합니다.
